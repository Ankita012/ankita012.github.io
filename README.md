# ankita012.github.io

This is my personal portfolio website built with React, Vite, and ShadCN UI. It showcases my skills, experience, and projects.

## Features

- Responsive design
- Animated background
- Contact form
- Skills section
- Experience timeline

## Getting Started

To run the project locally:

1. Clone the repository
2. Navigate to the `vite_react_shadcn_ts` directory
3. Install dependencies: `npm install`
4. Start the development server: `npm run dev`

## Deployment

The site is automatically deployed to GitHub Pages using GitHub Actions.

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- ShadCN UI
